# Glass Studio

本地 Vite 服务运行时打开 `http://127.0.0.1:5173/__glass/`。
控制台只在开发环境加载；正式构建不包含控制台、点选桥接或参数写入接口。

## 调整与保存

选择组件类型，或点选右侧真实网页中的组件。调节会即时应用到该类型的所有实例，
也会同步到同一开发服务下已打开或新打开的页面。页面切换不丢失未保存的预览。
调整其他类型不会改变导航选中透镜；导航的原有弹簧动画保持不变。

可调类型：文字按钮、社交按钮、导航底面、导航开关、导航选中透镜、项目悬浮遮罩、
Logo 底面、论文图片边框、About 照片边框、桌面滚动条。
每种渲染器只显示它实际支持的参数。导航底面与开关的尺寸仍遵循原有响应式布局。

- “保存为默认”将当前整套参数写入 `src/content/glass-settings.json`，下次启动仍保留。
- 输入名称后保存预设，可套用当前类型、套用整套，或将一种表面材质复制到其他表面类型。
- JSON 导入先进入预览，不会自动覆盖默认值；导出保存当前整套参数。

`原始毛玻璃 · 2026-10-04` 是受保护的原始预设，原始数值另存于
`src/content/glass-frosted-original.json`，控制台不可删除。
`清透按钮 · 导航保持原样` 是低模糊、低底色不透明度的候选预设，不自动启用。
仅调节或保存到本地不会更新公网网站；公网只使用下一次正式构建时的默认参数。

## 验证

`node scripts/verify-glass-studio.mjs` 检查同类联动、类型隔离、新窗口同步、页面切换、
持久化、点选、透镜参数、跨类型复制、JSON 导入导出、响应式控制台、原始预设保护、
跨来源请求与非法参数拒绝。测试结束恢复测试前的默认值并删除自己创建的测试预设。

生产构建另行检查不包含 `__glass`、`glass:preview`、控制台或开发点选代码。

## 视频与访问边界

微信宿主的 `WeixinJSBridgeReady` 事件会直接重试静音播放，包括旧请求仍在等待的情况。
宿主拒绝播放或视频无帧进度时，保留原 MP4 的逐帧解码动画兜底。
它不是 GIF；不支持解码的环境仍显示封面，不声称覆盖所有微信版本或所有平台。
模拟桥接测试不等同于真实 iPhone 微信验收，macOS WebKit 由现有 CI 单独检查。

大陆网络中已有 TCP/TLS 超时证据。控制台和播放改动不改变 GitHub Pages 的跨境链路。
域名/CDN 调整需要对应账户的管理权限，不能用海外正常访问替代大陆网络验收。
